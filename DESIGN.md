# Clarity Design System

## Mode
Operate — personal project execution workbench. Scanability and task completion outrank expression.

## World
Light modern desk. Cool paper/fog ground, near-black ink, single teal accent `#0f766e`.
Restrained neutrals. No marketing eyebrows, no section numbers, no decorative gradients.

## Tokens
- Base: `#f4f6f8`
- Raised: `#ffffff`
- Soft: `#eef1f4`
- Ink: `#111827`
- Muted: `#5b6775`
- Line: `rgba(17, 24, 39, 0.08)`
- Accent: `#0f766e`
- Danger: `#be123c`
- Radius: `10–12px`
- Ease: `cubic-bezier(0.16, 1, 0.3, 1)`
- Type: system UI stack (Segoe UI / PingFang / YaHei)

## Components
- Sidebar nav without numbered prefixes
- Filter chips, primary/secondary/danger buttons
- Right drawer for create/edit
- Cards with hairline borders, no heavy shadows
- Priority dots only for task priority
- Project color as small status mark only

## Motion
State feedback only, 150–200ms. No page-load choreography. Honor reduced motion.

## Breakpoint
Desktop shell ≥1100px with sticky sidebar; below that bottom tab bar.
